REST API Endpoints (Day 3):
  • POST /api/doctors - Create doctor
  • GET /api/doctors - List all doctors
  • GET /api/doctors?page=0&size=10 - Paginated list
  • GET /api/doctors/{id} - Get doctor by ID
  • PUT /api/doctors/{id} - Update doctor
  • DELETE /api/doctors/{id} - Delete doctor
  • GET /api/doctors/specialization?specialization=CARDIOLOGY - Filter by specialization
  • GET /api/doctors/search?name= - Search doctors by name
